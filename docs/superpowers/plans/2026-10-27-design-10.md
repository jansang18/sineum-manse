# 잔상 만세력 마감·접근성 개선 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Track verified steps below.

**Goal:** 피그마·유료 서비스 없이 기존 정체성과 계산·저장 형식을 보존하여 A–I를 개선하고 모든 배포 게이트 통과 시만 GitHub Pages에 배포한다.

**Architecture:** 정적 HTML의 의미 구조와 표시 함수, 기존 apple.css/reading.css/building-lookup.css를 최소 변경한다. 풀이 탐색은 문장 생성 엔진과 분리한 DOM 표현 계층으로 구현한다.

**Tech Stack:** HTML/CSS/JS, Node 내장 테스트, puppeteer-core/Chrome.

**Spec:** 작업 루트 CODEX_PROMPT_design10.md 및 docs/design-system.md, 최신 통합 화면 스펙.

## Global Constraints

- 공통 폭 1180px, 원국 440px/4열/정사각형, 운 흐름 48–64px, 본문16px/1.7/최대72ch 유지.
- 계산식·음력변환·저장키/구조·주소조회·연도 이동 로직 및 문장 생성 엔진 불변.
- 궁합·큰 점수 카드·인생 그래프를 재도입하지 않는다. 요약은 기존 문장의 짧은 텍스트로 표시한다.
- 캐시 비활성 정책, 개인 저장/설정 보존. 변경 자원 버전 쿼리 갱신.
- outputs/design-10은 저장소 밖 증거 폴더다. 전체 테스트 실패0, 계산3건 동일, 저장 이전/내보내기/불러오기, 콘솔오류0 전부 확인 전 push 금지.

## Review Focus

- 320px에서 12px 배지·십신이 겹치지 않는지 실제 박스로 측정.
- 저장된 테마와 OS 테마가 반대일 때 첫 페인트 및 theme-color가 올바른지.
- 연도/대운 재렌더 뒤 목차와 접힘 상태가 오래된 DOM을 참조하지 않는지.
- 이름 없음/받침 있는 이름/없는 이름/HTML 입력이 자연스럽고 안전하게 표시되는지.
- 저장 이전 데이터와 메모가 캐시 정리·공유·내보내기에 손상되지 않는지.

## Decisions

- D는 기능3개 안내(c)를 선택한다. 개인정보/새 계산경로 없이 데스크톱 빈 공간을 설명으로 활용한다.
- 탭 전환은 모두 페이지 맨 위로 이동한다. 목차 이동은 해당 제목에만 이동한다.
- 최신 요청의 월별 접기를 적용하되 연도→월별12개→대운 순서와 모든 원문을 DOM에 보존한다.
- 점수 중심 카드 금지 규격이 우선이므로 점수 요약 카드를 새로 만들지 않는다. 기존 수치가 있는 문장은 그대로 둔다.
