# 원국 하단 운 흐름 재배치 설계

- 작성일: 2026-08-12
- 상태: 사용자 승인
- 대상: `https://jansang18.github.io/sineum-manse/`
- 구현 범위: `app/web`

## 목표

원국 탭의 콘텐츠 순서를 다음과 같이 재배치한다.

1. 원국
2. 대운
3. 세운
4. 월운
5. 일운—월운에서 월을 선택했을 때만 표시
6. `1,000년 같은 기둥`

기존 대운·세운·월운·일운 계산과 상태 로직은 재사용하고, 중복 컴포넌트나 별도 계산 엔진을 만들지 않는다.

## 현재 구조와 변경 지점

현재 `renderResult()`는 `.oguk-card` 뒤에 `renderSamePillars60(...)`을 렌더한 후, `.result-right > .luck-section`에서 대운과 하위 운 흐름을 표시한다. 이 순서를 바꾸어 `.luck-section`을 `.oguk-card` 직후와 `renderSamePillars60(...)` 사이에 둔다.

`luck-section`의 동적 하위 구조는 현재 방식을 유지한다.

- `#daeunScroll`: 대운 선택
- `#seunArea`: 선택된 대운의 세운
- `#woonArea`: 선택된 세운의 12개 월운
- `#dayArea`: 선택된 월의 일운

이 전체 동적 영역이 `1,000년 같은 기둥` 앞에 있으므로, 월운과 일운을 펼친 후에도 1,000년 카드는 항상 가장 뒤에 이어진다.

## 데이터와 상태 흐름

1. 원국 계산 후 현재 대운을 자동 선택한다.
2. 현재 대운의 세운을 즉시 표시한다.
3. 세운을 선택하기 전에는 월운·일운 DOM과 별도의 빈 카드를 만들지 않는다. 선택 후에만 같은 `luck-section` 안에 점진적으로 표시한다.
4. 다른 대운을 선택하면 `selectedSeun`과 `selectedWoon`을 초기화하고, 세운·월운·일운을 선택된 대운에 맞게 다시 구성한다.
5. 세운을 선택하면 월운을 표시하고 기존 일운 선택은 초기화한다.
6. 월운을 선택하면 해당 연월의 일운 달력을 월운 바로 아래에 표시한다.

새로운 외부 API, 저장 포맷, 계산 규칙은 추가하지 않는다.

## 시각 설계

- 첨부 이미지의 구조처럼 대운과 세운을 하나의 읽기 흐름으로 묶는다.
- 기존 `priestess.css`/`apple.css`의 먹색 표면, 오행별 색상, 명조계 한자, 카드 재질감을 유지한다.
- `ui-ux-pro-max`가 일반적으로 제안한 핑크·유기적 테마는 현재 브랜드와 충돌하므로 적용하지 않는다.
- 현재/선택 대운은 열 전체를 묶는 선명한 외곽선으로 표시한다. 색상만으로 상태를 구분하지 않는다.
- 대운, 세운, 월운, 일운은 제목·간지·십성 계층을 유지해 읽는 순서가 바뀌지 않게 한다.

## 반응형과 접근성

- 561px 이상 화면에서는 대운·세운 열을 한 줄에 전체 표시한다.
- 560px 이하 화면에서는 한자와 십성을 지나치게 줄이지 않고, 흐름표 내부만 가로 스크롤하도록 한다.
- 560px 이하 화면의 각 선택 항목은 최소 44px 터치 폭을 유지한다.
- 첫 표시 시 현재/선택 대운이 보이는 위치로 내부 스크롤을 맞춘다.
- 대운·세운·월운 선택 항목은 기본 버튼 요소로 구현하여 탭, Enter, Space로 조작할 수 있게 한다.
- 선택 상태는 각 버튼의 `aria-pressed`로 제공하고, 접근성 이름에 기간·천간 십성·천간·지지·지지 십성과 현재 여부를 포함한다.
- 스크롤은 본문 전체에 수평 오버플로를 만들지 않고, 흐름표 내부에만 제한한다.
- 기존 `prefers-reduced-motion`, `prefers-reduced-transparency`, `prefers-contrast` 대응을 보존한다.

## 예외 처리

- 원국 계산이 성공한 경우에만 운 흐름을 렌더한다. 입력 검증과 계산 오류 처리는 기존 흐름을 유지한다.
- 대운·세운·월운 선택이 바뀌면 더 깊은 단계의 오래된 선택과 DOM을 즉시 초기화해 서로 다른 기간의 데이터가 섞이지 않게 한다.
- 새 네트워크 요청을 추가하지 않으므로 오프라인 PWA 계산 가능 범위는 변하지 않는다.

## 검증 계획

### 구조 검증

- DOM 순서가 `.oguk-card` → `.result-right .luck-section` → `.same-pillars-card`인지 검사한다.
- 초기 렌더에서 현재 대운이 선택되고 `#seunScroll`이 존재하는지 검사한다.
- 세운 선택 후 12개 월운이 `1,000년 같은 기둥` 앞에 렌더되는지 검사한다.
- 월운 선택 후 일운 달력이 월운 바로 아래와 `1,000년 같은 기둥` 앞에 렌더되는지 검사한다.
- 상위 기간을 변경했을 때 하위 선택 상태와 남아 있는 DOM이 초기화되는지 검사한다.

### 사용성 검증

- 390px, 768px, 1220px 화면에서 문서 전체 수평 오버플로와 카드 잘림이 없는지 검사한다.
- 390px에서 대운·세운 항목의 최소 터치 폭, 내부 가로 스크롤, 현재 대운 초기 노출을 검사한다.
- 키보드로 대운 → 세운 → 월운을 선택할 수 있고 선택 상태가 제대로 갱신되는지 검사한다.
- 라이트/다크, 고대비, 줄인 동작 환경에서 가독성과 선택 외곽선을 검사한다.

### 회귀 검증

- 기존 `tests/ui-regression.js`에 순서·선택·반응형 계약을 추가한다.
- 기존 원국, 대운, 세운, 월운, 일운 개수와 간지 계산 결과가 변하지 않았는지 검사한다.
- 공개 배포 후 GitHub Pages 상태, HTTP 200, 실제 DOM 순서와 선택 상호작용을 다시 검사한다.
- 프리캐시된 CSS 또는 HTML 변경이 설치형 PWA에도 전달되도록, 해당 자산이 서비스 워커 캐시에 포함되면 캐시 버전 갱신을 함께 검증한다.

## 범위 제외

- 사주 계산 규칙 변경
- 1,000년 같은 기둥 검색 로직 변경
- 다른 탭의 정보 구조 변경
- 새로운 테마·폰트·아이콘 의존성 추가
- Android `app/www` 동기화나 APK 릴리스

## 성공 기준

- 사용자가 승인한 순서로 원국과 운 흐름이 표시된다.
- 월운에서 월을 선택하면 일운이 월운 바로 아래에 나타난다.
- 월운·일운의 펼침 여부와 관계없이 `1,000년 같은 기둥`은 항상 운 흐름 뒤에 있다.
- 기존 계산 결과와 다른 탭에 회귀가 없다.
- 모바일과 키보드 사용자가 모두 대운·세운·월운을 선택할 수 있다.
