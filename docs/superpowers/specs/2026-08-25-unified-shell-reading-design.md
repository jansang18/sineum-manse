# 잔상 만세력 통합 화면·풀이 재구성 설계

## 목적

입력·원국·풀이·만세력·저장 화면마다 달라진 폭, 상단 영역, 카드 크기와 여백을 하나의 화면 체계로 통일한다. 풀이 화면은 카드와 펼침 영역으로 잘게 나뉜 현재 구조를 걷어내고, 사용자가 위에서 아래로 자연스럽게 읽을 수 있는 한 편의 판독문으로 다시 구성한다.

## 확정 범위

- 궁합 탭, 궁합 선택 화면, 궁합 결과 화면을 사용자 인터페이스에서 제거한다.
- 큰 종합 점수 카드와 점수 중심 표현을 제거한다.
- 인생 총운 그래프와 그래프 조작 영역을 제거한다.
- 풀이 순서를 `해당 연도 종합 풀이 → 12개월 월별 풀이 → 현재 대운 풀이`로 고정한다.
- 입력·원국·풀이·만세력·저장 탭의 바깥 폭, 상단 소개 영역, 본문 여백과 카드 표현을 공통 규격으로 통일한다.
- 기존 원국·세운·월운·대운 계산 로직은 유지한다. 이번 작업은 정보 구조, 표시 순서, 문장 구성과 시각 체계를 정리하는 작업이다.

## 화면 체계

### 공통 유동형 셸

모든 탭은 같은 좌우 경계 안에서 시작하고 끝난다. 고정 픽셀 폭을 탭마다 다르게 지정하지 않고, 공통 CSS 변수와 `min()`·`clamp()`·`minmax()`를 사용한다.

- 접힌 폴드와 작은 휴대전화: 화면 양쪽에 작은 공통 여백만 남기고 가용 폭을 모두 사용한다.
- 일반 스마트폰: 카드와 원국 칸이 화면 폭에 맞춰 연속적으로 늘어나며, 고정 폭 때문에 빈 공간이나 잘림이 생기지 않게 한다.
- 펼친 폴드: 휴대전화용 좁은 최대 폭을 강제로 적용하지 않고 내부 디스플레이의 가용 폭을 사용한다. 단, 본문 줄 길이는 별도로 제한한다.
- 태블릿·데스크톱: 셸은 화면에 맞춰 유동적으로 넓어지되 최대 폭을 제한한다. 넓은 화면에서는 원국·달력처럼 폭이 필요한 영역만 확장하고 텍스트는 읽기 폭을 유지한다.
- 긴 풀이 본문: 셸 전체 폭 안에서 별도의 읽기 폭을 적용해 한 줄이 지나치게 길어지지 않게 한다.
- 표·원국·달력처럼 폭이 필요한 요소: 같은 셸 안에서 본문보다 넓게 사용할 수 있다.

이 구조로 탭 전환 시 좌우 경계가 움직이지 않으면서도 각 콘텐츠가 필요한 폭을 얻는다.

특정 기기 이름에만 맞춘 고정 폭 대신 다음 규칙으로 동작한다.

- 바깥 셸: `width: min(100% - 공통 여백, 공통 최대 폭)`
- 원국·표·카드 묶음: `repeat(..., minmax(0, 1fr))`로 남은 폭을 균등 배분
- 글 본문: `max-inline-size`를 글자 수 기준으로 제한하고 셸 중앙에 배치
- 화면 회전·폴드 상태 변경: 페이지를 다시 열지 않아도 즉시 새 가용 폭으로 재배치
- 콘텐츠가 좁아질 때: 가로 스크롤을 만들지 않고 간격과 글자 크기를 `clamp()` 범위 안에서 완만하게 축소

### 공통 상단 영역

각 페이지의 첫 영역은 같은 높이와 패딩 체계를 사용한다. 큰 장식 배너 대신 다음 세 요소만 둔다.

1. 짧은 화면 이름
2. 현재 보고 있는 대상 또는 날짜
3. 필요한 경우 한 줄짜리 보조 설명

페이지별 제목 크기, 위아래 간격, 테두리 위치를 같게 만들어 탭을 바꿔도 화면 골격이 유지되게 한다. 원국처럼 별도의 핵심 시각 요소가 바로 시작되는 화면은 빈 배너를 만들지 않고 동일한 시작 간격만 적용한다.

### 시각 언어

- 기존 잔상 만세력의 어두운 먹색·금색 계열을 유지한다.
- 카드마다 제각각인 둥근 정도, 테두리, 배경 농도를 공통 토큰으로 통일한다.
- 큰 제목보다 굵기와 간격으로 위계를 만든다.
- 본문 크기는 모바일에서도 읽기 편한 수준을 유지하되, 불필요한 대형 문구는 없앤다.
- 장식용 영문 소제목과 반복 라벨은 줄이고 한국어 정보가 먼저 보이게 한다.

## 풀이 정보 구조

풀이 화면은 여러 독립 카드나 펼침 패널의 모음이 아니라 하나의 연속된 판독문으로 표시한다. 세 구간은 충분한 여백과 얇은 구분선, 명확한 번호·제목으로 구분하며 기본 상태에서 모두 보인다.

### 1. 해당 연도 종합 풀이

- 선택 연도의 세운과 원국 관계를 한 흐름으로 설명한다.
- 내용은 `올해의 핵심 → 일·재물 → 관계·생활 → 건강·주의 → 실행 기준` 순서로 이어진다.
- 기존의 여러 점수표와 다섯 개 이상의 펼침 카드는 제거한다.
- 필요한 명리 근거는 본문 끝의 짧은 근거 줄로 모아 중간 읽기 흐름을 끊지 않는다.

### 2. 12개월 월별 풀이

- 선택한 연도의 1월부터 12월까지 시간순으로 표시한다.
- 각 달은 `월 · 월간지 · 핵심 흐름 · 실제 행동 기준` 순서로 쓴다.
- 한 달을 하나의 가로 행으로 사용하며, 화면 폭에 따라 문장 영역이 자연스럽게 늘고 줄어든다.
- 모바일에서도 좌우 스크롤이나 두 칼럼을 만들지 않는다.
- 월간지는 기존 절기 기준 계산을 사용하며, 월 대표값 산출 기준을 하단에 짧게 안내한다.

### 3. 현재 대운 풀이

- 현재 선택된 대운이 만드는 약 10년의 배경과 현재 연도의 관계를 설명한다.
- 내용은 `대운의 성격 → 현재 연도와 겹치는 지점 → 활용 방법 → 주의할 선택` 순서로 쓴다.
- 기존 인생 총운 그래프, 전환점 점수, 전체 연령별 지수표는 표시하지 않는다.
- 사용자가 원국 화면에서 다른 대운을 선택하면 이 마지막 구간만 해당 대운 기준으로 다시 구성한다.

## 탐색과 상태

- 기존 `이전 해 · 올해 · 다음 해` 연도 탐색은 유지한다.
- 연도를 바꾸면 연도 종합 풀이와 월별 풀이가 함께 바뀐다.
- 대운 선택은 원국 화면의 기존 대운 흐름을 유지하고, 풀이 마지막 구간에 선택 상태를 반영한다.
- 펼침/접힘에 의존하지 않으므로 사용자가 내용의 위치를 예측할 수 있다.

## 제거와 정리

- 상단 내비게이션에서 궁합 탭을 제거하고 남은 탭을 같은 비율로 재배치한다.
- 궁합 모달과 궁합 결과 렌더링 진입점을 제거한다.
- 현재 중단된 궁합 재구성 테스트는 폐기하고, 궁합 UI가 노출되지 않는 회귀 계약으로 교체한다.
- 점수 카드와 인생 그래프에만 쓰이던 스타일과 이벤트 연결을 제거한다.
- 계산 데이터가 다른 기능에서 사용되는 경우 계산 함수까지 무리하게 삭제하지 않고 UI 의존성만 분리한다.

## 접근성과 반응형 기준

- 320, 360, 390, 412, 520, 600, 720, 768, 884, 1024, 1280, 1440픽셀에서 가로 넘침이 없어야 한다.
- 폴드 접힘·펼침과 세로·가로 회전 후에도 같은 탭의 콘텐츠가 즉시 재배치되어야 한다.
- 모든 탭의 왼쪽·오른쪽 경계 차이는 1픽셀 이내여야 한다.
- 상단 영역의 높이와 본문 시작 위치는 콘텐츠가 한 줄인 경우 같은 규격을 유지한다.
- 연도 이동과 대운 선택은 키보드로 접근 가능하고 최소 44픽셀 터치 영역을 유지한다.
- 텍스트 확대, 다크·라이트 모드, 고대비, 모션 축소 설정에서 정보가 사라지지 않아야 한다.
- 긴 한국어 본문은 적절한 행간과 문단 간격을 사용하며 데스크톱에서 과도하게 긴 한 줄을 만들지 않는다.

## 검증

- 화면 셸: 모든 탭의 실제 브라우저 좌우 경계와 시작 위치 비교
- 풀이 순서: 연도 종합, 월별 12개, 대운 풀이의 DOM 순서 확인
- 제거 계약: 궁합 탭·궁합 화면·큰 점수 카드·인생 총운 그래프가 표시되지 않는지 확인
- 상태 전환: 이전 해·올해·다음 해와 대운 선택 후 관련 판독문만 정확히 갱신되는지 확인
- 명리 회귀: 기존 월간지·세운·대운 계산 결과가 변경되지 않았는지 대표 경계값 비교
- 시각 QA: 휴대전화·태블릿·데스크톱 화면 캡처로 여백, 줄 길이, 상단 높이와 전체 균형 확인
- 보안 회귀: 저장된 이름과 메모 같은 사용자 입력이 풀이·저장 화면에서 HTML로 실행되지 않는지 유지 확인

## 완료 기준

탭을 이동해도 화면의 가로 경계와 상단 리듬이 흔들리지 않고, 풀이 탭을 열면 해당 연도의 전체 의미를 먼저 이해한 뒤 1월부터 12월까지의 흐름과 현재 대운의 배경까지 한 번에 이어서 읽을 수 있어야 한다. 궁합, 큰 점수 카드, 인생 총운 그래프는 사용자 화면에 남지 않아야 한다.
