# 잔상 만세력 UI 규격

2026-09-08 사용자 승인: 기존 먹색·금색 분위기를 유지하면서 페이지와 글자 박스의 규격을 통일한다.

## 단일 기반

- `apple.css`: 공통 색상, 글꼴, 화면 폭, 입력·버튼, 명식·운 흐름, 접근성 및 피드백.
- `reading.css`: 연도 종합 → 12개월 → 대운의 연속형 읽기 화면.
- `building-lookup.css`: 주소 조회 전용 상태와 배치. 공통 변수를 사용한다.
- `polish.css`, `luxury.css`, `priestess.css`는 참고용으로 남겨 두지만 페이지에서 로드하지 않는다. 추가 테마로 덮어쓰지 않는다.

## 크기와 글꼴

| 역할 | 규칙 |
| --- | --- |
| 공통 화면 | 최대 1180px, 화면에 따른 좌우 여백, 모든 탭에서 동일한 경계 |
| 일반 입력·주요 버튼 | 최소 높이 52px, 모서리 10px |
| 아이콘·보조 버튼 | 터치 영역 최소 44px |
| 카드 | 모서리 16px, 한 겹의 은은한 테두리 |
| 원국 | 최대 440px의 4열, 정사각형, 네모 안쪽 폭의 60% 글자 |
| 대운·세운·월운 | 공통 `--app-flow-cell` 48–64px, 같은 모서리·글자 비율; 개수로 크기를 바꾸지 않음 |
| 일운 | 7열 정사각형, 날짜 / 한자 두 글자 / 십신 두 항목; 최소 폭 44px |
| 본문·일반 UI | 시스템 고딕, 본문 16px, 일반 굵기 |
| 제목 | 20–24px, 소제목 18–20px |
| 한자 | 명조, 본문용 글꼴과 역할 분리 |
| 긴 풀이 | 최대 72ch 읽기 폭, 월별 내용은 모든 화면에서 단일 열 |

운 흐름이 화면보다 길면 그 영역만 가로로 스크롤한다. 페이지 전체를 가로로 밀거나 글자를 축소하지 않는다. 헤더는 내용에 맞게 늘어나며 긴 이름과 건물 출처를 자르지 않는다.

## 동작 보존

계산식, 음력 변환, 저장, 주소 조회 및 연도 이동 로직은 그대로 유지한다. 성공 토스트, 입력 오류, 화면 낭독기 알림은 공통 기반에서 관리한다. 선택은 외곽선과 색으로 표현하며 네모의 크기를 바꾸지 않는다.

서비스워커 캐시 종료 및 앱 캐시 정리 규칙을 유지한다. 변경된 자원은 버전 쿼리로 갱신한다. 저장된 명식과 개인 설정은 캐시 정리 대상으로 삼지 않는다.

## 검증

`tests/design-consistency-ui.js`는 320, 390, 720, 884, 1280, 1440px의 밝은/어두운 테마에서 실제 계산·클릭 후 크기, 선택 안정성, 읽기 순서, 터치 영역, 글자 겹침 및 대비를 측정한다. 캡처 전 유한한 테마 전환과 글꼴 로딩의 완료를 기다린다.

기존 `tests/ui-regression.js`의 기능·접근성 검사는 유지하되 제거된 테마 이름이나 이전 색상에 묶인 검사만 새 공통 변수에 맞춘다. 실제 기기의 설치·렌더링 여부는 브라우저 검사나 APK 서명 검사와 별도로 보고한다.
