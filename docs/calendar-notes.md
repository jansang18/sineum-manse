# 날짜 메모

만세력 월 달력 또는 원국의 일운 달력에서 날짜를 누르면 메모를 작성할 수 있다.
기록한 날짜에는 작은 체크 표시가 생긴다. 같은 월일이어도 다른 연도에는 반복되지 않는다.
메모는 기기의 localStorage에 저장되며 웹과 APK, 다른 브라우저/기기 사이에 자동 공유되지 않는다.

- 입력: 정확한 양력 연·월·일, 날짜당 자유 메모 2,000자 이내.
- 편집: 날짜 클릭 → 메모 수정 → 저장. 닫기는 저장하지 않고 편집을 취소한다.
- 삭제: 삭제 → 삭제 확인. 해당 날짜만 삭제한다.
- 키: `jansang_calendar_notes_v1`, 문서 버전 1.
- 날짜 키: `YYYY-MM-DD`. 음력 표시는 참고 정보이며 저장 키는 달력의 양력 날짜이다.
- 새로고침 후 유지. 기존 명반 저장 및 캐시 정리 정책과 별도 저장한다.
- 저장 실패 시 성공 표시를 하지 않는다. 손상된 저장 문서는 자동 덮어쓰지 않는다.
- 표시에는 `textContent`를 사용하며 메모를 HTML로 실행하지 않는다.

구현은 `calendar-notes.js`/`calendar-notes.css`, 두 달력 연결은 `index.html`에 있다.
두 파일은 Android 릴리스 자산 목록에도 포함된다. 설치한 APK의 파일은 재빌드해야 갱신된다.
사이트 데이터 삭제 또는 앱 삭제 시 이 기기에 저장된 메모도 삭제될 수 있다.

검증:

```powershell
node --test tests/calendar-notes.test.js
node tests/calendar-notes-ui.js
```

브라우저 검사는 저장·다시 열기·정확한 날짜 구분·수정/취소·확인 후 삭제,
저장 실패·HTML 입력 안전성·키보드와 포커스·화면 크기별 마크 위치를 확인한다.
`CALENDAR_NOTE_URL`, `CALENDAR_NOTE_WIDTHS`, `CALENDAR_NOTE_THEMES`로 검증 대상을 지정한다.
